# Step 4 工艺与生产规则引擎交付说明

验收日期：2026-09-14。开发范围为 Step 4，本机 SQLite 与文件存储保持原有方式。

## 使用入口

- 打开 http://127.0.0.1:3210/ ，侧边栏新增「规则中心」。
- 管理规则：规则中心 →「登录管理」→ 使用 `data/规则管理账号.txt` 中的管理员账号 → 新建、编辑、复制或启停规则。
- 设计师账号可以查看规则、核对 Logo 特征、补充材质与表面资料。未登录为业务模式，可执行预审和确认警告，不能维护规则或核对资料。
- 任务中心 → 查看任务 →「工艺预审」→ 按 SKU 选择工艺 →「保存选择并重新评估」。
- 缺少生产 Logo 时，先进入「Logo 预处理」创建并确认当前版本。
- WARNING：填写确认说明并提交；NEED_INFO：由设计师或管理员补资料后重新评估；BLOCK：更换工艺。所有角色均没有临时绕过 BLOCK 的入口。
- 管理员核实真实工艺后，可复制示例规则，填写真实依据，取消「验收示例」标记并发布。系统不会根据产品照片猜测实际制造能力。

启动方式不变：继续双击「双击启动AI效果图智能助理.cmd」或原有启动入口。数据库随工具服务打开，不必手动启动另一项数据库服务。访问地址仍为 `127.0.0.1:3210`。

## 1. 已完成功能

1. 规则中心：编号、名称、作用范围、条件、提示、结果、硬软类型、状态、版本、更新时间；搜索及状态、范围、结果、硬软类型、工艺筛选。
2. 条件式规则表单：字段、运算符、值，多条件 AND；工艺、视觉色、是/否使用下拉选择，数值使用数值输入。支持新增、复制、发布新版本、历史只读查看、版本化启停。
3. 六类作用范围：全局、SKU、产品类别、材质、表面处理、Logo；支持需求文档中的八种运算符。
4. 七种统一工艺：普通、黑色、白色、金色、银色印刷，以及烫金、烫银。视觉金色不会自动设置工艺。
5. 按任务产品独立预审：每个 SKU 返回七种候选状态，BLOCK 候选禁用，展示原因及推荐替代方案，支持一键选择推荐工艺并重新评估。
6. 保存评估时记录当前生产 Logo、产品资料、母版区域、命中规则及版本、当时业务说明、推荐方案、整体结果。
7. 历史评估只读；规则、工艺、材质资料、Logo 核对资料、当前生产 Logo 或母版区域变化后，旧评估不能继续作为就绪依据。
8. 警告确认留痕；硬禁止和待补资料不能通过确认按钮绕过。就绪检查只表示预审完成，本阶段没有效果图生成入口。
9. 产品材质与表面处理、Logo 特征核对均采用独立资料版本，不覆盖原 Product 或 ProductionLogo 记录。
10. 本机管理员 / 设计师账号、服务端权限检查、密码散列和登录会话。账号文件不通过网站对外提供。
11. 初始化九条规则。其中六条是文档默认颜色 / 资料规则；三条 SKU / 表面工艺示例明确标记并默认停用。启用示例得到的结果不能作为真实生产放行依据。

页面路径采用应用原有哈希路由：`/#/rules`、`/#/rules/new`、`/#/rules/[id]`、`/#/tasks/[taskId]/rules`。

## 4. 规则聚合与就绪判断

引擎位于独立 `rule-engine.mjs`。先组装当前任务产品的资料，再读取启用的当前规则。每条规则的条件按 AND 计算；只有全部成立才命中该结果。已知条件为假时跳过；没有已知假值而存在未知依赖时返回 NEED_INFO，不把未知当成不匹配或 PASS。

整体优先级：**BLOCK > NEED_INFO > WARNING > PASS**。

- HARD + BLOCK：禁止就绪，任何角色不能临时绕过；需更换工艺，或管理员维护规则后重新评估。
- NEED_INFO：补资料、核对事实或制作适配 Logo 后重新评估，不能用警告确认代替。
- WARNING：必须记录确认说明，且结果仍是最新有效评估。
- PASS：在结果有效、没有示例规则参与时预审就绪。低风险工艺资料齐全且无限制时可通过。
- 烫金和烫银默认需要材质、表面处理，并命中明确适用的正式工艺允许规则。缺少限制规则不能据此自动认定高风险工艺可做。
- 对当前资料和规则再次计算校验摘要；规则、策略、Logo、资料或区域变化，以及新评估替代旧评估，都会使旧就绪依据失效。

## 5. 八项验收结果

| 场景 | 实际验证 | 结果 |
| --- | --- | --- |
| Case 1：1–2 色 | 已知像素构造的单色、双色生产 Logo，普通印刷均 PASS；显示颜色规则 | 通过 |
| Case 2：3 色 | WARNING；未确认不可就绪，空说明被拒绝，提交有效说明后就绪并保存确认记录 | 通过 |
| Case 3：多色 / 渐变 | 五色、渐变分别 NEED_INFO；另验证半透明；不能用确认接口忽略 | 通过 |
| Case 4：禁止工艺 | L0048 测试硬规则禁止烫金；浏览器选项禁用，管理员不能强制确认；推荐金色印刷可切换重评 | 通过 |
| Case 5：仅视觉金色 | 生产 Logo 为金色，未选工艺仍为 null、NEED_INFO，没有自动写为烫金 | 通过 |
| Case 6：缺材质 | 选择依赖材质的工艺返回 NEED_INFO；补齐材质和表面后，缺少正式工艺允许规则仍不放行 | 通过 |
| Case 7：多 SKU 差异 | 同一生产 Logo 下不同 SKU 分别 PASS、WARNING、BLOCK；候选和结果独立，页面可逐项查看 | 通过 |
| Case 8：规则追溯 | V1 评估保留原提示和版本；V2 新评估生效；启停创建后续版本，过时发布冲突被拒绝；重启后历史不变 | 通过 |

额外验证：业务 / 设计师不能写规则；未知值参与 NOT_EQUALS / NOT_IN 不会误放行；示例规则结果禁止实际就绪；工艺策略变化使旧结果失效；源 PNG 字节不变；登录会话和历史重启恢复。

自动测试：`test-step4.mjs`。浏览器验收包含账号登录、规则搜索、新规则表单、只读版本、任务入口、禁选、推荐切换、警告确认、历史和 390px 窄屏；未发现页面脚本错误。
