# 母版拖动与图片预览优化 · 2026-11-04

本轮用户确认：默认摆放框宽、高独立调整；实际 Logo 保持原始比例。

## 已实现

1. 绿色默认摆放框新增四条边的中点：上下中点只改变高度，左右中点只改变宽度，仍以中心缩放。四角可同时调整两维。蓝色可印范围、红色禁止区域和图片边界校验继续生效。
2. 修复区域拖不动、选中状态意外消失：绿色预览层原用内联 style 关闭鼠标响应，但应用的 Content-Security-Policy 禁止内联样式，导致该层截获点击。改用 SVG 的 pointer-events 属性，不放宽安全策略。拖动已选区域时不反复重建属性表单；保留鼠标指针捕获并避免面板滚动锚定。
3. 完成效果图可点击放大，支持按钮和滚轮缩放、100% 原尺寸、适合窗口、放大后拖动、Esc 或关闭返回。保留当前产品、结果和下载勾选。历史效果图也使用同一查看器。
4. Logo 库各版本可点击或键盘打开预览；透明背景以棋盘格显示。创建任务时，从库选 Logo 的窗口也支持先预览、再选择。

小虚线框显示等比例 Logo 示例；它不会随绿色范围任意拉伸，扩大范围也不保证文字必然变大（另一边仍可能限制等比例尺寸）。

## 验证

- 28 项隔离浏览器检查通过，覆盖独立缩放、宽度已到蓝框边缘仍能增高、Shift 拖动副本、撤销重做、草稿恢复、发布后读回、成品/Logo 预览、缩放平移、复用选择、文件读取失败提示、小窗口和无脚本异常。
- 11 项现有相关检查通过：中心缩放与旋转几何、母版方向保存、撤销重做、角色权限、历史与重启、区域工艺和判色。权限测试需要本机测试服务器访问，已在允许该访问的隔离环境重新验证。
- 对放大预览和母版界面做实际截图检查。
- 浏览器验收在独立数据库与文件副本进行；正式更新仅替换程序文件，发布脚本在更新前做最新数据快照，并对更新后的所有业务数据表和资料文件逐项校验。

## 使用

- 母版：点击“拖动／中心缩放默认框”，拖上下中点调高度、左右中点调宽度。点击“选择 / 移动”可回到蓝色区域的整体移动。
- 完成效果图或 Logo 库：点击图片打开大图；关闭后回到原操作位置。
- 网页入口：http://127.0.0.1:3226/#/tasks 。更新后按 Ctrl+F5 载入新界面；未发布草稿仍使用原保存键恢复。

本轮不改变业务数据结构，不清空产品图库、任务或 Logo 库。
