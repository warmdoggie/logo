# Step 6A 多 SKU 批量处理交付说明

日期：2026-09-14。代码和隔离测试已完成，正式服务已于本次故障修复中成功切换至新版。重启电脑后双击原来的「双击启动AI效果图智能助理.cmd」即可启动，地址仍为 http://127.0.0.1:3210/ 。启动文件未改变，SQLite 随工具打开，不需要单独启动数据库。

## 1. 已完成功能及使用路径

任务中心 → 查看任务 → 效果图工作台：先完成代表 SKU 首图的六项人工审核，建立任务风格。再进入「批量应用与结果」，勾选其余 SKU，进行批量预检，逐条处理警告，然后启动生成。

- 每个 SKU 使用自身任务绑定的母版版本、产品图和区域，优先保留已有草稿位置。
- 独立显示可生成、警告、待补资料、禁止、缺少母版、缺少区域及需调整状态；禁止和资料不足不能绕过。
- WARNING 每个 SKU、每次尝试独立确认；生成前重新检查规则及确认有效性。
- 复用 Step 5 PNG 渲染器；保留效果图版本、参数快照、Logo 使用引用和旧图片。
- 任务中心和详情展示批量进度；工作台链接可直接定位待调整 SKU。
- 结果页支持历史版本、单张下载、六项人工审核和批量 ZIP 下载。

正式旧任务未自动补绑母版、未自动确认首图。已有三个任务缺少母版绑定，应按 Step 5 流程准备完整的新任务后使用批量功能。

## 5. 数据库变化

新增六张表，启动新版时通过 CREATE TABLE IF NOT EXISTS 创建，不删除或改写原有业务表：

| 表 | 用途 |
| --- | --- |
| TaskStyleRevision | 追加 Logo 联动风格版本，引用原首图风格 |
| BatchJob | 批次、冻结风格与 Logo、整体状态 |
| BatchItem | 每 SKU 的预检、警告确认、尝试次数和错误 |
| BatchAttempt | 追加每次尝试的事件与快照 |
| BatchOutput | 批次尝试与已提交效果图版本的关联 |
| BatchExport | ZIP 文件、内容清单和 SHA-256 |

原 TaskStyleMaster 保持不变；联动版本使用附加表，版本号在两张风格表之间连续分配。旧版本和旧 Logo 引用保留。正式服务已重启，六张新增表已创建且没有测试数据；原有 30 张表逐字段核对一致，13 个上传文件 SHA-256 保持一致。

## 6. 队列、恢复及 Logo 联动

全局最多同时生成两个 SKU，同一 SKU 加锁，单项失败不拖垮其他项。只允许重试失败项，每次重试重新预检和确认警告。输出和批次关联在同一事务提交，防止恢复后重复生成。

重启后检查中断任务：已提交图片恢复为待审核或已通过；未提交项目标记为可重试的中断失败，批次暂停，等待用户重试，不自动无限重跑。

Logo 新版激活后检测旧图影响范围。工艺和视觉方向一致时，经明确确认追加任务风格版本；变化时要求重新确认代表 SKU。新 Logo 保留原中心并按新宽高比等比适配；超界、禁区冲突或规则禁止时阻止生成，不强制贴入。

## 7. ZIP 与审核

每张图必须完成六项人工检查，勾选要审核的结果后提交。没有“一键全部通过”。ZIP 只包含当前有效、审核通过的结果；选中无效项时拒绝该次导出。旧 Logo、过期规则、未审核和失败结果不能混入交付 ZIP。

单图名为「客户_SKU_工艺_LogoVx_MockupVx.png」。历史单张可查看和下载，但不因此获得交付资格。ZIP 采用 UTF-8 文件名并记录清单与摘要；已验证浏览器下载及 Windows 解压读取 PNG。

## 8. 验收、回归及数据核对

Step 1—5 自动回归通过。Step 6A 隔离接口测试与浏览器测试通过，覆盖：

1. 10 SKU 使用各自母版和位置。
2. PASS、WARNING、NEED_INFO、BLOCK 独立分类。
3. WARNING 逐项、逐次确认。
4. 缺母版、多个区域无默认选择时阻止入队。
5. 两路并发和单 SKU 排他处理。
6. 单项文件故障不影响其他项生成。
7. 仅重试失败项，避免重复已提交版本。
8. 未完成六项检查时拒绝审核，完成后允许通过。
9. ZIP 排除未审核及规则过期图。
10. Logo V1→V2 影响检测和部分更新。
11. 全部受影响项更新，规则禁止项继续独立阻止。
12. 新宽高比保留中心、适配尺寸，旧 PNG 字节保留。
13. 重启中断恢复、人工重试和历史追踪。
14. 浏览器筛选、进度、下载、SKU 定位、窄屏和无脚本错误。

正式数据核对结果见 Step6A正式数据核对.json；对照开发前备份逐字段比较原有表，并核对上传文件 SHA-256。测试数据全部写入隔离目录，没有导入正式库。
