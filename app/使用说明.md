# AI效果图智能助理 本地版

目前已完成 Step 1 产品与任务管理、Step 2 产品母版和 Step 3 Logo 预处理。分别参见同目录 Step2验收说明.md、Step3验收说明.md。你提供的 5 个产品已入库，另有一个 Rae.（测试）任务，关联全部 5 个产品，客户要求为“单色 Logo”。

## 打开与启动

访问 http://127.0.0.1:3210 。关闭浏览器不会删除数据。

电脑重启后，在本文件所在文件夹双击 `双击启动AI效果图智能助理.cmd`（原 `start.cmd` 也可用），会在后台启动工具并打开浏览器。重复双击会复用已运行的工具。请保留整个项目文件夹，不能只移动启动文件。

不需要账号或密码，只绑定本机地址 127.0.0.1，同事无法从其他电脑访问。没有开机自动启动。当前使用电脑已有的 Node.js 24 运行环境；若以后移除该环境，需要安装 Node.js 24 或更高版本。

## 使用流程

1. 打开“产品图库”，查看已入库产品。点击图片可放大查看。
2. 点击“新增产品”，填写 SKU、名称、类别并上传标准图。
3. 打开“任务中心”，点击“新建任务”。
4. 输入客户名称，选择一张原始 Logo，搜索并添加产品，填写客户要求。
5. 多个 SKU 可以使用换行、中英文逗号、分号或空格分隔。点击“查找并添加”后会显示找到和未找到的列表；仅精确找到的产品会添加，重复 SKU 自动去重。
6. 点击“创建任务”。在任务详情查看资料，下载原始 Logo，或返回任务中心重新打开。

上传支持 PNG、JPG、WebP，单张不超过 12 MB。Logo 原文件按原始字节保存，下载时恢复上传文件名。Step 3 的原始 Logo 新版上传另支持独立静态 SVG；任务初始上传仍使用 PNG/JPG/WebP，不支持 PDF、AI、PSD。

## 数据与项目结构

```text
AI效果图智能助理/
  start.cmd           双击启动入口
  start.ps1           本机启动与浏览器打开
  server.mjs          本地服务、上传、校验、数据库与接口
  storage.mjs         文件存储适配层
  schema.sql          数据库结构
  package.json        项目与运行信息
  test.mjs            接口与重启持久化验收
  public/
    index.html        页面入口
    app.js            五个页面与交互
    style.css         桌面与窄屏样式
    favicon.svg       工具图标
  seed/               你提供的原始测试素材副本
  data/
    assistant.sqlite  真实 SQLite 数据库
    uploads/          入库产品图和任务 Logo
    server.log        运行日志
    server-error.log  错误日志
```

数据保存在 `data` 文件夹，不依赖浏览器缓存。不要删除该文件夹。要备份，可重启电脑后、打开工具前复制整个项目文件夹到其他位置；这样数据库和图片能一起保存。

| 表 | 主要字段与约束 |
| --- | --- |
| Product | id、sku、name、category、standardImage、createdAt、updatedAt；SKU 大小写不敏感且唯一 |
| Task | id、taskCode、customerName、rawRequirement、status、createdAt、updatedAt；任务编号唯一 |
| LogoAsset | id、taskId、fileName、filePath、createdAt；每个任务绑定一张原始 Logo |
| TaskProduct | id、taskId、productId；任务与产品多对多，同一任务不可重复关联同一产品 |
| AppMeta | 初始化版本标记，避免每次启动重复导入示例 |

任务、Logo 信息和产品关联在同一个数据库事务中保存。提交失败时回滚数据库写入并清理本次上传文件。SKU 搜索优先展示精确匹配，另支持 SKU 前缀和产品名称模糊搜索；批量输入只进行精确匹配。

## 技术方案调整

文档中的 Next.js、React、TypeScript、PostgreSQL、Prisma 是建议方案。本机版实际采用原生 JavaScript 页面、Node.js 本地服务与 SQLite，免安装额外依赖和数据库服务。数据真实持久化，没有使用浏览器存储或 Mock 数据替代业务数据库。文件存储独立封装在 storage.mjs，可在后续改为对象存储。

如需以后改用多人共享服务器，应另行迁移部署与权限方案；本版适合当前这台电脑使用。
