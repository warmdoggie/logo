# S7 Logo Stability

新增入口「多 Logo 上样」支持同一产品、多个 Logo、各四张效果图；使用方法、功能开关与回退步骤见 [MULTI-LOGO.md](MULTI-LOGO.md)。

集成在主工作区中的 Logo 上样模块，通过主服务 `/s7/` 路径提供页面和 API，与主工作区共用登录会话和产品图库；每个用户的任务草稿、素材和结果仍保存在独立空间。模块从同一布局输出四个版本：

- `ORIGINAL`
- `BLACK`
- `GOLD FOIL`
- `SILVER FOIL`

## 四套整图方案

上样目标通过画布上方的悬浮横条编辑，默认收起；可拖动六点手柄移动工具栏，展开后横向选择目标、调整载体和工艺，并可点击“回到画布上方”归位。工具栏与主工作区共用产品图库、Logo 库和用户会话，右侧仍保留独立任务列表。

单击画布中的 Logo 可选择一个，Ctrl + 单击（Mac 使用 ⌘）可追加或取消选择，也可勾选工具栏每个位置前的复选框。所有选中 Logo 显示外框、缩放方块和旋转箭头，浮动工具栏保留 Logo 勾选及载体、工艺设置，不再展示批量数值输入区。多选后可直接拖动某个已选 Logo 的蓝色方块，统一调整选中同类 Logo 的大小；单击其旋转箭头可统一逆时针旋转 90°，长按箭头后拖动可统一自由旋转。彩盒和产品分别操作，保留全部选择与各自位置。大小、角度通过画布手柄直接调整。大小和角度更新当前 SKU 全部版本中的对应选中区域，包括独立摆放方案，保留各自中心和透视；未选中区域保持原值。自定义颜色通过左侧 HEX 输入修改，作用于该 SKU 全部同类 Logo。切换 SKU、Logo 或版本后，多选回到当前单个位置，避免误改其他上下文。

同一任务选择多个 SKU 后，展开工具栏点击“同步设置…”，在弹窗中按“全部可同步设置 → 彩盒 / 产品 → 搭配 → 参数”勾选范围。父级支持全选和部分选中，右侧列出本次修改范围及接收 SKU，确认后才应用。产品提供五种搭配；彩盒只提供原色、黑白、自定义，不提供烫金、烫银。各搭配可同步大小和角度，只有自定义搭配可同步颜色；其他搭配颜色固定，不参与颜色同步。默认勾选当前载体、当前搭配，不自动全选。彩盒原色搭配的大小、角度同时应用到烫金、烫银方案中的彩盒区域，产品设置和颜色保持原值；在烫金、烫银方案中选中彩盒时，弹窗默认勾选彩盒原色分支。

产品同步以弹窗中的“产品参考 Logo”为准，默认使用当前选中的产品 Logo，也可在弹窗切换。所选搭配的大小、角度或自定义颜色应用到所有已选 SKU 的全部产品 Logo，包含当前 SKU；参考值取该 Logo 在对应搭配中的设置。彩盒同步仍只应用到其他 SKU，大小和角度按相同载体及区域顺序对应。所有 Logo 保留各自位置，四点区域保留接收方透视后按原图像素比例缩放、旋转；没有对应区域的设置跳过，未勾选的分支保持原值。四点区域超出原图，或已选择 Logo 时普通区域的尺寸、角度超出接收图范围，本次应用明确失败，不会只修改部分接收 SKU。修改随任务草稿保存，用于后续批量生成，已有成图需要重新生成才会更新。

同一张产品图以原色方案、黑白方案、烫金搭配、烫银搭配四张卡片展示。卡片可分别勾选生成、进入编辑、查看大图和下载。四套方案均使用本地合成，不需要配置或调用外部生图模型；单产品、多产品、多 Logo 和队列生成共用同一处理。原色与黑白直接使用定位贴图，保留颜色和透明边缘；烫金、烫银再增加各自材质处理，金属渐变、原图明暗、细小纹理及薄边缘均限制在 Logo 字形内。AI Logo 加工仍可单独使用。

方案列表顶部提供与卡片相同的圆形“全选”框。初始仅勾选原色和黑白，全选框为空心；点击后勾选全部五套方案，再次点击全部取消。多 SKU 共用生成选择，全选及全部取消也同步更新所有已选 SKU 的成图下载选择；已有任务继续恢复保存的选择。

编辑画布只显示当前选中 Logo 的边框和手柄。点击画布空白处取消选中并隐藏所有边框，再点击 Logo 或目标卡片可重新编辑。

点击生成后立即显示“正在生成”，并锁住提交按钮和产品／Logo 切换，待提交返回后恢复切换。保存及提交期间不会重复发起生成；失败时显示错误并恢复重试入口。生成准备只处理勾选的方案，不预先合成未选中的图片。

新建任务时先输入 1–80 个字的名称，取消或留空均不会创建任务；新账号进入空列表时也不会自动创建。任务名称始终由用户设置，可在任务栏手动修改，保存或替换素材不会自动命名。

Logo 素材框点击后获得粘贴焦点，不打开文件选择窗口；复制图片后按 Ctrl+V 粘贴，也可拖入图片文件。文件选择使用框外独立的“选择 Logo 文件”入口。上传、拖入、粘贴共用现有素材导入及任务保存流程，支持多张图片；在搜索框、名称等文字输入位置粘贴时保留正常文字编辑行为。多 Logo 数量及产品搭配限制保持原有规则。

- 产品包材与彩盒正背面分别设置工艺、普通颜色；彩盒允许原色及黑白普通印刷，禁止烫金烫银。黑白方案默认按实际 Logo 字形覆盖处的底色自动选择黑色或白色，透明留白不参与取色，并跟随旋转、四点透视和曲面弯曲位置；其他搭配的彩盒默认保留 Logo 原色。
- 摆放默认同步到所有共用布局的方案；选择“仅当前方案”后，位置、尺寸和角度可独立调整，并可恢复公共摆放。具有独立摆放的方案不会被其他方案的公共摆放修改覆盖。
- 颜色、工艺仅修改当前方案，各方案分别保留自己的印刷效果。
- 新建区域默认保留 Logo 原色；取消“使用 Logo 原色”后可指定单色。已有任务的显式颜色继续保留。
- 生成结果逐张保存、展示；修改后标记“有修改，待重新生成”，可比较修改预览与上次成图，也可只重新生成修改过的方案。生成使用提交时的方案快照，生成期间继续编辑的内容仍会标记待生成。
- 四套方案、独立摆放、选色及结果指纹随任务保存恢复。重新生成期间保留旧图，失败不会清除其他方案的结果。
- 多产品任务也直接在各产品的四张预览卡片中显示成图：生成时卡片内展示环形进度，完成后标记“已生成完成”，不再在底部重复展示生成历史。切换产品、任务或刷新后恢复相同的图片与阶段。
- 多产品生成在服务端后台逐张保存；个人任务可单独重试某张图，其他已完成图片保留。旧版多包材生成历史会自动恢复到预览。浏览器刷新不会中断生成；服务重启会标记未完成图片，可使用已保存的远端任务信息重试。
- 自动保存只发送变化的草稿字段；任务列表使用轻量摘要，临时网络错误保留当前工作界面。
- 每张预览右下角使用圆形下载选择框：没有成图时禁用，新成图默认选中，可取消；选择随任务保存。右上角“下载到文件夹”先选择保存位置，再创建以客户名称命名的文件夹，保存当前客户任务所有产品勾选的原 PNG；图片内容、命名和顺序与原批量下载一致，最多 200 张、300 MB。同名目录自动加序号，不覆盖原文件夹；中途失败会提示已保存数量及所在文件夹。需要支持目录写入的浏览器（如最新版 Chrome、Edge），不支持时会提示更换浏览器。
- 成图卡片使用最长边 1200 像素的 WebP 预览，当前任务内复用已加载图片，并在四张都解码后一起切换；产品标签使用 192 像素缩略图。放大查看和下载继续读取原 PNG，预览生成不修改原图。切换成图无需等待编辑原图加载。

已发布母版通过载体语义关联识别彩盒，也支持区域名称含“彩盒”“纸盒”或“carton”。缺少语义和明确名称的旧区域需要手动选择载体。GPT 与 Flux 按每套方案接收独立区域参数、定位参考图和遮罩，金属光效仅应用于该方案中实际使用金属工艺的区域。

## 当前边界

- 输入：一张产品/彩盒原图、一张透明 Logo、一个或多个明确的上样目标。
- 输出：四张独立 PNG、目标 ID、统一布局指纹和每个目标的边界信息。
- 保护：Logo 以外的原图像素不被模块主动修改。
- 校验：目标不能为空、目标 ID 不能重复、Logo 不能越出原图。
- 交互：画布支持移动、缩放和旋转，左侧参数会同步更新。
- Logo 加工：页面已把本地 Logo 加工合并到“生成选中的方案”：单 Logo、多 Logo、多产品及重新生成请求自动携带 `processLogo:true`，服务端读取完整原图后先本地去底、去噪、统一主色和平滑，再按所选印刷方案生成；加工失败时不提交生成任务。本地加工没有独立按钮或颜色弹窗，不调用图片模型；复杂 Logo 可使用下述“AI 精细化处理”。独立 `/api/process-logo` 接口保留供离线验证兼容使用。纯色底图通过边缘带估计底色，去除外部和字母内部同底色区域，并恢复底色混合形成的半透明边缘；识别到完整截图边框时，同时去除贴边的残留色块。黑色模式统一 RGB 为纯黑；保留主色模式归并相近实色，在单色占比超过 90% 时归并不足 3% 的同色明暗杂色，保留不同色相的点缀；超过 16 组主色时跳过归并。透明度按有效覆盖值（Alpha ≥ 32）判断连通区域，去除不超过 3 像素的孤立杂点；低透明度像素仅保留紧邻笔画的抗锯齿边缘，轻度平滑后再次去噪。与附近同色竖笔对齐的小字母点会保留，尺寸不变。自动加工保留图片尺寸及上传原图，不改变摆放参数；清理后的图片用于本次生成，生成结果按原有流程保存。适合平面纯色 Logo，极小标点、复杂背景、与图案同色的背景及渐变设计需核对，不能还原已经丢失的文字和轮廓。
- 多位置上样：每个目标都是一个独立 Logo 实例；点击“复制 Logo”可复制当前实例并自动错开位置，之后可单独移动、缩放和旋转。
- 服务：由 `server.mjs` 在 3210 端口直接挂载，不需要单独运行 3237 端口的服务。

## 本地 Logo 加工

可完全离线对已有透明 PNG 试效果，不调用图片模型、不写入 Logo 库：

```powershell
node s7-logo-stability/preview-logo-refinement.mjs 输入.png ../outputs/logo-refinement/试处理 black
```

最后一个参数可改为 `original`，保留主色并归并相近颜色。输出目录包含 `before.png`、`after.png`（真实透明 PNG）和 `comparison.png`（灰底前后对比及局部放大）。验证：`node --test test-logo-refinement.mjs`。

## AI 精细化处理

在“选择 Logo 文件”下方点击“AI 精细化处理”，只处理当前选中的 Logo。该入口复用现有 APIMart endpoint、apiKey、proxyUrl、timeoutMs 和 logoModel，以原图为参考请求透明 PNG，保留原色、金属渐变、纹理与高光。成功后更新当前任务、保存到 Logo 库，并提供“下载透明 PNG”；原始上传数据保留，失败时不替换当前图片。已有透明通道仍需模型重新处理，因此应按需点击。

返回图片必须包含可见内容和真实透明像素。精细化结果不会再经过本地主色归并；任务草稿、浏览器缓存和 Logo 库均保留精细化标记，刷新或再次使用时延续该处理方式。Logo 库会自动为旧数据库添加默认关闭的标记列。AI 可能改变细节，完成后需核对字形、细线和留白，不能保证逐像素保真。

本地服务更新后需要重启，再刷新页面。验证：`node --test test-ai-logo-refinement.mjs test-logo-library.mjs`；真实 APIMart 调用另行消耗图片额度。

## AI 接口配置

AI 精细化处理使用以下配置；原有本地 Logo 加工不依赖这些参数。

S7 读取 `01_Source_Code/data/ai-provider.local.json`，也可以使用环境变量 `S7_AI_CONFIG` 指向配置文件。APIMart 配置示例：

```json
{
  "enabled": true,
  "provider": "APIMART",
  "model": "gpt-image-2.5-flare",
  "mockupModels": ["gpt-image-2.5-flare", "flux-3-image"],
  "endpoint": "https://api.apimart.ai",
  "apiKey": "只保存在本机配置，不要提交到 Git"
}
```

`model` 是默认的最终上样成图模型；`mockupModels` 是前端可选的最终成图模型列表。Logo 透明底加工继续使用 `logoModel`（未配置时回退到 `model`），因此 `flux-3-image` 不会意外替换透明 Logo 加工模型。

S7 会向 APIMart 提交 `/v1/images/generations` 图片编辑请求，使用 Logo 的 base64 data URL，支持直接返回图片链接或异步任务后下载结果。当前允许模型：`gpt-image-2.5-flare`、`gpt-image-2`、`wan2.7-image-pro`、`wan2.7-image`。精细化处理建议使用已配置的 `logoModel: "gpt-image-2.5-flare"`，显式请求透明背景及 PNG，画布比例按输入图选择。下载结果必须是带透明背景的 PNG，否则会直接提示失败，不会使用本地抠图算法兜底。

金银版本当前是确定性颜色版本，尚未加入真实金属反光。AI 材质融合会在后续阶段通过受保护遮罩接入。

## 产品母版位置

每个 SKU 现在提供第五个“自定义配色”方案。点击该方案的“编辑此方案”，通过 HEX 分别填写产品和彩盒的 Logo 油墨颜色；彩盒正反面共用彩盒颜色。选择多个 SKU 时，通过工具栏“同步设置…”勾选要同步的载体、搭配与参数。勾选自定义方案的圆形选择框后参与生成，旧任务重新打开时会补齐该方案。

在同步弹窗中，自定义颜色按产品和彩盒分组应用，不受彩盒正反面或区域数量差异影响。若只同步彩盒颜色，只勾选“彩盒 → 自定义配色 → 颜色”；产品颜色与其他搭配保持原值。

S7 通过主工作区的 `/api/templates/:productId` 读取产品当前已发布母版。产品库选择产品后，所有 `logo` 区域会自动转换为固定上样目标；目标的坐标、尺寸、方向和四点区域由母版提供，S7 画布中的几何编辑会被锁定。需要调整位置时，请回到主工作区的“产品母版”页面修改并重新发布版本。

没有已发布母版的产品仍可在 S7 中手动定位；产品标准图发生变化并需要重新确认母版时，S7 不会继续使用旧区域。

Windows 上通过项目根目录的 `start-workspace.ps1` 启动主工作区，之后从左侧导航打开 S7；旧的 `start-s7.ps1` 入口也会转到主工作区启动脚本：

```powershell
cd C:\Users\EDY\Desktop\AI_LOGO
powershell -ExecutionPolicy Bypass -File .\start-workspace.ps1
```

在 `01_Source_Code` 目录运行：

```powershell
node --test s7-logo-stability/test.mjs
```
