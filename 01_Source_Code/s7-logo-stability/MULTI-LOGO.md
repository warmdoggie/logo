# 多 Logo 用于同一产品

入口：主工作空间 → S7 → 任务栏「＋ 新建任务」。普通任务统一支持一个 Logo 配一个产品、一个 Logo 配多个产品、多个 Logo 配一个产品；不支持同时选择多个 Logo 和多个产品。原有多 Logo 任务也会打开这个统一编辑器。

1. 从产品库选择一个产品。需要有已发布且不需要重新复核的产品母版，包含至少一个 Logo 区域。
2. 从 Logo 库添加，或一次上传多个 Logo。多个 Logo 模式支持 2–20 个 Logo；有背景的素材先选中对应缩略图，再点击「AI 加工 Logo（透明底）」，可保留原色或转为黑色。
3. 选择现有成图模型，点击生成。每个 Logo 单独用于同一产品的所有母版 Logo 区域，分别输出原色、黑白、烫金搭配、烫银搭配四张完整产品图。两个 Logo 共八张。
4. 上方缩略图展示不同 Logo，点击后下方切换为该 Logo 与同一产品的四种方案预览和结果。各 Logo 的编辑布局独立保存，可单独重生成某一方案、查看大图，或勾选后统一打包下载。刷新页面可恢复选择、布局和结果。

初始位置、角度、大小和透视沿用产品母版；可以使用普通任务已有的编辑器分别调整各 Logo 的方案。沿用现有原色保留、深底自动白字、彩盒普通印刷、金银工艺和非 Logo 区域保护规则。银箔也沿用原模块当前的渲染方式。

## 隔离与恢复

- 入口、素材选择和预览统一到普通任务；继续复用队列及 API `/s7/api/ai-render-logos`，单 Logo 及一 Logo 多产品的生成算法和提示词保持原有行为。
- 新草稿为 `mode: ordinary`，多 Logo 生成记录仍为 `kind: multi-logo`；兼容旧 `mode: multi-logo` 草稿，通过现有用户空间保存，无数据库结构迁移。
- 每张图片立即保存，后台按 Logo 顺序执行，一个 Logo 内沿用现有四工艺生成器。切换任务、刷新、退出登录后可恢复查看。
- 服务重启会把未完成任务标记为中断，保留已保存图片及上游任务检查点；点击重试只处理未完成版本。上游任务仍有效时复用其编号，避免重复提交。
- 同一任务运行时拒绝重复启动和删除，跨用户任务和图片访问沿用现有权限校验。

## 关闭与代码回退

快速关闭只需要设置环境变量并重启现有服务；正在执行的任务先等待结束。已有素材、历史结果和旧模块均保留。

Windows，在项目根目录的 PowerShell 中：

```powershell
$env:S7_MULTI_LOGO_ENABLED = '0'
.\start-workspace.ps1
```

先停止原服务，再执行启动命令；启动脚本会拒绝重复占用 3210 端口。恢复时将变量设为 `'1'` 后重启。Linux/systemd 部署时在现有服务的 Environment/环境文件中设置同名变量并重启。

关闭后普通任务不可新增第二个 Logo，已有多 Logo 任务的生成按钮禁用，生成接口返回 404；现有多 Logo 任务仍可打开查看和下载结果。关闭开关不会停止已提交的后台任务。

本功能分支为 `codex/multi-logo-print`，改动前基线为 `fc86884`，保留在本地 `main`。若需要完整代码回退，在无未提交改动并停止服务后执行 `git switch main`，再启动服务。此操作不删除忽略目录中的业务数据；功能分支仍可切回。完整回退后通过原有任务继续工作，新增多 Logo 任务请在恢复功能分支后打开。

## 验证

在 `01_Source_Code` 目录运行：

```powershell
node --test s7-logo-stability/*.test.mjs s7-logo-stability/test.mjs test-s7-integration.mjs
npm test
```

新增测试覆盖两 Logo 八图、逐张保存与归属、失败补图、透明度校验、关闭开关、原模块兼容、重复生成和删除保护、跨用户隔离、服务重启与上游检查点、素材变更拦截、母版复核，以及原色和深底白字像素。

自动测试与浏览器验收使用本地替代模型验证调用参数和保存流程，未调用付费外部成图服务；真实模型最终视觉质量沿用现有服务，仍应在发布环境用实际 Logo 验收。

合并后的回归测试还覆盖每个 Logo 的独立布局、单方案重生成、独立下载勾选、历史任务恢复、AI 加工期间切换 Logo、加载期间移除和快速切换返回。浏览器验收覆盖三种组合、八图生成、下载、刷新恢复及旧任务迁移。
